# Agentes del proyecto

Copia de los agentes de [Agency Agents](https://github.com/msitarzewski/agency-agents) (commit f99f6aa, licencia MIT, ver `LICENSE-agency-agents`) que usa este proyecto según la tabla de la sección 1.b de `PROMPT_MAESTRO.md`.

Están en el repo para que también los tengan las sesiones de Claude Code en la nube (claude.ai/code), que clonan el repo y no ven `~/.claude/agents` de la PC. Si se suma un agente a la tabla, copiar su `.md` acá sin modificarlo.
